# Privacy

- CVs, preferences, matches, drafts and application notes are processed in the browser and normally stored in its local storage.
- No CV or individual search query is submitted to the scheduled data collector. Collection uses fixed public engineering-title queries.
- The site fetches a public snapshot from the same GitHub Pages site. GitHub can receive normal request/network information; consult GitHub's privacy statement.
- No analytics, advertising scripts or third-party fonts are added by this app.
- Optional AI, when enabled and explicitly used for individual scoring or drafting, sends CV, preferences and advert text to the provider endpoint you configure. That provider has its own policies. Snapshot searches themselves remain local even when this toggle is enabled.
- AI keys are held in memory, cleared on reload and excluded from backups. Never enter a GitHub personal access token into the website.
- Backups include private CV/application data. Keep them out of public repositories.
- Reset app data clears this app's browser storage. It cannot delete copies you downloaded or information previously sent to an AI provider.
- Moving between a local file, old preview URL and GitHub Pages does not transfer browser storage. Export and restore privately if needed.
- Anyone can inspect public job snapshots and frontend code. They contain no user CV database or authentication secrets.
